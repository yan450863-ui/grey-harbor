# 素材与开发接手指南

游戏工程版本：3.0.47。资料整理日期：2026-10-24。

## 下载与摆放

1. 按仓库 README 用 Git LFS 克隆源码，打开 `UnityProject`；主游戏使用 Unity **6000.6.3f1**。
2. 在 [v3.0.47 Releases](https://github.com/yan450863-ui/grey-harbor/releases/tag/v3.0.47) 下载 `GreyHarbor-3.0.47-Assets-and-Handover.zip` 和 `GreyHarbor-3.0.47-Assets-SHA256SUMS.txt`。
3. 把素材压缩包中的 `asset-handover` 文件夹解压到仓库根目录，与 `UnityProject`、`docs` 并列。辅助素材不需要全部导入 Unity 即可运行当前游戏。

```text
grey-harbor/
├─ UnityProject/                 当前游戏工程
├─ docs/                         公开构建和接手说明
└─ asset-handover/                从 Releases 解压的资料包
   ├─ README.md                  资料包导航与接手步骤
   ├─ PROJECT.md                 当前版本与源码入口
   ├─ LICENSE                    项目自有资料的 MIT 许可证
   ├─ manifest.csv               每个资料文件的大小与 SHA-256
   ├─ package-summary.json       范围、统计与排除记录
   ├─ 公共素材与档案/             原始素材、设计和制作源
   └─ 游戏版本/灰港行动_3.0.47/   当前版本的制作说明与必要报告
```

## 从哪里接手

| 任务 | 资料包中的入口 |
| --- | --- |
| 理解当前玩法、价格与规则 | `公共素材与档案/当前设定/游戏规则.md`；最终以当前 Runtime 和配置为准 |
| 查找美术、原图、模型和 Unity 包 | `公共素材与档案/素材索引.md`、`公共素材与档案/美术素材/ABOUT.md` |
| 修改菜单候选视觉 | `公共素材与档案/美术样稿` |
| 接着做联合转运中心 | `公共素材与档案/后续设计/待制作与问题.md`、一楼草图 V2 与墙体障碍可编辑草图 |
| 制作、重新组装或定位原图 | `公共素材与档案/制作源/素材制作`，含生成记录、脚本及 `原图路径索引.json` |
| 修改手电与瞄准镜着色器 | `公共素材与档案/制作源` 下三个独立工程 |
| 查看当前版系统实现说明 | `游戏版本/灰港行动_3.0.47/制作档案` |
| 查阅旧设定与参考 | `公共素材与档案/参考设计`；旧稿不替代当前规则 |

主工程已经包含运行所需的 Resources、StreamingAssets 和资源 GUID。素材文件夹名中的版本号表示制作批次，不能据此删除或覆盖现有资源。72 件候选收藏品后来已全部接入，接入状态以当前索引和代码为准。

## 制作源的使用方式

- 保留 `.meta` 与资源配对；先在独立副本或分支验证导入，避免重新生成 GUID。
- 三个着色器工程均保留 Assets、Packages、ProjectSettings 和 Output；圆形手电照明工程为 **6000.6.3f1**，手电着色器工程及瞄准灰雾着色器工程为 **6000.6.2f1**。以各自 ProjectVersion.txt 为准。
- 制作脚本、生成记录和部分文档保留历史绝对路径、旧版本路径及生成服务记录。它们用于溯源，不是下载者机器上的有效位置；运行脚本前先修改输入、输出路径。
- 有些原图已经按 SHA-256 去重，先用 `原图路径索引.json` 的 `oldSource` 查 `retained`，再从资料包根目录定位。不要因为旧路径不存在就重新生成美术。
- 独立工程导出的同名资源包可能是历史版本；不能直接覆盖主游戏 `StreamingAssets` 的当前资源包。
- `.unitypackage` 用 Unity 导入；`.excalidraw`、SVG、JSON 为继续编辑的设计源；PNG/JPG 为预览和图片素材。

## 范围、许可与验证

资料包包含全部公共素材目录中可交接的文件，排除 Unity Library、Logs、UserSettings 等可再生成或本机文件；没有删除作者的原文件。另附当前版制作说明、布局 JSON、试玩说明与已有 QA 报告；不包含个人存档和存档保护快照，也不打包所有历史游戏版本。

项目自有代码、美术、制作源和文档随项目按 MIT 许可开放。参考设计中的外部参考图片、品牌标识及第三方内容保留原权利，不因本资料包而获得新的授权；Unity 及其组件遵循各自许可。

包内 `manifest.csv` 列出资料文件的相对路径、字节数和 SHA-256；打包时与原始目录核对，并验证压缩包可完整读取。原始素材与制作档案保持内容一致，接手说明和统计文件为本次新增。

本次包内共有 **5,421 个原始资料文件**，原始内容 610,055,148 字节；排除 837 个缓存、日志与本机文件。压缩包内每个原始文件已通过 SHA-256 校验，42 项去重原图映射均存在且哈希一致。

发布压缩包大小为 566,281,082 字节（约 540 MiB），SHA-256：`e2abb376b09d87fb73942d7af9bc1f7fb60c7a35aad7682122fef76845a9723e`。

本次只补充接手资料，没有修改游戏逻辑，也没有重新宣称全游戏验收。工程构建及黑雾专项的既有验证范围见仓库 `docs/verification/publication-checks.md`。素材候选、历史说明、尚未接入的模型和未来设计不表示已实现或已验证。
